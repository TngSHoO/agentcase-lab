# 产品决策记录

## 为什么第一版使用模拟数据

真实 Agent 日志往往包含个人信息、商业数据和 API 密钥。第一版用结构化模拟数据验证信息架构、诊断流程和展示方式，避免为了接入日志 SDK 扩大项目范围。模拟数据必须在页面和文档中明确标识。

## 为什么先做规则演示模式

作品集需要能够稳定演示。仅依赖在线模型会受到余额、网络和模型输出波动影响，因此默认使用可复现的规则报告；配置 API Key 后再启用实时分析。

## 为什么不自动执行修复

Agent 的提示词、权限和工具参数可能影响真实业务。MVP 只提供建议与复测对比，不直接修改生产配置，以保留人工决策责任。

## 为什么同时展示成本和延迟

只追求成功率可能导致更长上下文、更强模型和更多重试，从而放大成本与延迟。产品验收必须同时观察质量、性能和成本。
