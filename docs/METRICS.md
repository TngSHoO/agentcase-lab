# 指标体系

## 北极星指标

**有效故障闭环率**：进入平台的失败案例中，完成定位、提出修复并通过复测的案例比例。

## 结果指标

- 任务成功率
- 修复后通过率
- 同类问题复发率
- 严重故障占比

## 效率指标

- 平均故障诊断时长
- 从发现到复测通过的平均周期
- 单案例人工检查步骤数

## 成本与性能指标

- 平均响应时间
- P95 响应时间
- 平均 Token 数量
- 单任务模型调用成本
- 工具重试次数

## 质量护栏

- 根因分析人工认可率
- 错误归因率
- 无证据结论比例
- 高风险修复的人工确认覆盖率

演示数据不用于宣称真实业务效果。简历中只有经过实际测试的数据才可以写成量化成果。
