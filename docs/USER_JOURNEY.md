# 用户旅程

| 阶段 | 用户行为 | 当前痛点 | AgentCase Lab 方案 |
|---|---|---|---|
| 发现 | 从用户投诉或监控中发现失败 | 只看到最终答案，不知道中间发生了什么 | 将案例集中进入故障列表 |
| 定位 | 翻阅分散日志 | 日志格式不一致，产品经理难以理解 | 用统一时间线展示六类执行步骤 |
| 归因 | 召集研发、算法讨论 | 团队分类口径不同 | 使用七类根因标签和证据字段 |
| 修复 | 修改提示词或工具参数 | 修改理由和版本缺少记录 | 保存修复方案与预期影响 |
| 验证 | 人工重跑任务 | 只看答案是否成功，忽略成本与速度 | 同时对比成功、延迟、Token 和成本 |
| 沉淀 | 在文档中记录结果 | 案例无法复用 | 将成功复测加入黄金样本集 |
