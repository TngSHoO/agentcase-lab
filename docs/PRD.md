# AgentCase Lab 产品需求文档

## 1. 产品背景

AI Agent 的最终输出可能正确，也可能因为提示词、检索、工具、上下文、记忆或权限问题而失败。传统日志通常只能告诉团队“哪里报错”，不能帮助产品、运营和算法人员快速理解“为什么失败、应该改什么、修复是否有效”。

AgentCase Lab 将一次 Agent 运行转换为可浏览的时间线，提供结构化根因分析，并对比修复前后的成功率、延迟、Token 与成本。

## 2. 目标用户

- 负责 Agent 功能设计和验收的 AI 产品经理
- 负责提示词、知识库和工具配置的 AI 应用团队
- 负责线上 Bad Case 运营与质量复盘的运营人员

## 3. 核心问题

1. 一次失败跨越多个模型和工具步骤，定位成本高。
2. 团队对 Bad Case 的分类口径不一致。
3. 修改提示词后缺少统一的效果验证。
4. 成功率改善可能以更高延迟和成本为代价。

## 4. MVP 范围

### 包含

- 质量与成本数据看板
- 故障案例筛选与详情
- 六步骤运行轨迹回放
- 七类根因分析
- 修复前后对比
- 无 API Key 的演示模式
- OpenAI 兼容的实时分析接口

### 暂不包含

- 直接构建或运行第三方 Agent
- 自动修改线上提示词
- 团队权限与审批流
- 生产级日志采集 SDK
- 自动执行高风险修复

## 5. 核心流程

发现异常 → 筛选案例 → 回放轨迹 → 定位首次失败步骤 → 生成根因报告 → 提出修复方案 → 对比复测结果 → 沉淀黄金样本。

## 6. 验收标准

- 首次启动自动生成 30 条演示案例。
- 每条案例包含完整的六步骤轨迹。
- 七种根因类型均有覆盖。
- 无 API Key 时所有核心页面可使用。
- 配置 API Key 后可以生成结构化实时分析报告。
- 修复对比同时展示任务状态、延迟、Token 和成本。
